## Documentation Standards

When adding new documentation:

1. **Keep it up to date** - Update docs when code changes
2. **Be clear and concise** - Write for developers of all levels
3. **Use examples** - Include code samples where helpful
4. **Cross-reference** - Link to related documentation
5. **Structure well** - Use clear headings and sections
